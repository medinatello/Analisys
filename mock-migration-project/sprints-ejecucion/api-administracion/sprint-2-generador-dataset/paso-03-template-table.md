# Paso 3: Crear Template para Tablas

**Duracion estimada:** 25 minutos
**Prerequisitos:** Paso 2 completado

## Objetivo
Definir template para generar archivos *_table.go con metodos FindByID y List.

## Codigo a Implementar

Agregar a dataset_generator.go:

```go
const tableTemplate = ` + "`" + `// Code generated by mock-generator. DO NOT EDIT.

package dataset

import (
	"sync"
	"github.com/EduGoGroup/edugo-infrastructure/postgres/entities"
	"github.com/google/uuid"
)

type {{ .TableCamel }}Table struct {
	data map[uuid.UUID]*entities.{{ .EntityName }}
	mu   sync.RWMutex
}

func New{{ .TableCamel }}Table() *{{ .TableCamel }}Table {
	return &{{ .TableCamel }}Table{
		data: make(map[uuid.UUID]*entities.{{ .EntityName }}),
	}
}

func (t *{{ .TableCamel }}Table) FindByID(id uuid.UUID) *entities.{{ .EntityName }} {
	t.mu.RLock()
	defer t.mu.RUnlock()
	
	if item, ok := t.data[id]; ok {
		return item
	}
	return nil
}

func (t *{{ .TableCamel }}Table) List() []*entities.{{ .EntityName }} {
	t.mu.RLock()
	defer t.mu.RUnlock()
	
	items := make([]*entities.{{ .EntityName }}, 0, len(t.data))
	for _, item := range t.data {
		items = append(items, item)
	}
	return items
}
` + "`" + `
```

## Validacion

### Criterio de Exito
- [ ] Constante tableTemplate definida
- [ ] Template incluye FindByID
- [ ] Template incluye List

### Comandos de Validacion
```bash
grep -q "tableTemplate" pkg/generator/dataset_generator.go && echo "OK: Template definido"
grep -q "FindByID" pkg/generator/dataset_generator.go && echo "OK: FindByID en template"
```
