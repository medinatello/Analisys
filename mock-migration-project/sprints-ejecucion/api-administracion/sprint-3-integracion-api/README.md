# Sprint 3: Integracion con API Administracion

**Duracion estimada:** 4-5 horas
**Objetivo:** Integrar dataset generado en api-administracion y estandarizar configuracion

## Descripcion General

Este sprint aplica el dataset generado a api-administracion, actualiza los mock repositories, estandariza la configuracion, y realiza pruebas end-to-end completas.

## Prerequisitos

- Sprint 0, 1 y 2 completados
- Generador funcional
- api-administracion clonada

## Pasos del Sprint

1. **paso-01-generar-dataset.md** - Generar dataset para api-admin
2. **paso-02-copiar-dataset.md** - Copiar archivos generados
3. **paso-03-actualizar-user-repository.md** - Actualizar UserRepository mock
4. **paso-04-actualizar-school-repository.md** - Actualizar SchoolRepository mock
5. **paso-05-actualizar-academic-unit-repository.md** - Actualizar AcademicUnitRepository mock
6. **paso-06-actualizar-membership-repository.md** - Actualizar MembershipRepository mock
7. **paso-07-actualizar-factory.md** - Verificar factory.go
8. **paso-08-estandarizar-config.md** - Estandarizar variable USE_MOCK_REPOSITORIES
9. **paso-09-actualizar-debug-json.md** - Actualizar .zed/debug.json
10. **paso-10-borrar-archivos-antiguos.md** - Limpiar archivos hardcodeados
11. **paso-11-compilar-api.md** - Compilar api-administracion
12. **paso-12-probar-health.md** - Test de health check
13. **paso-13-probar-login.md** - Test de autenticacion
14. **paso-14-probar-endpoints.md** - Test de endpoints completos
15. **paso-15-validacion-final.md** - Validacion completa del sistema

## Resultado Esperado

Al finalizar:
- api-administracion usa dataset generado
- Mock repositories simplificados
- Configuracion estandarizada
- Todas las pruebas pasan
